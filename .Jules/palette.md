## 2023-11-08 - Explicit Form Label Binding and ARIA Labels for Icon Buttons
**Learning:** Implicit label wrapping (putting an input inside a label tag) or simply placing a label next to an input without `htmlFor` matching the input's `id` does not always guarantee full screen reader compatibility or reliable click-to-focus behavior across all browsers, particularly with customized input components or certain CSS frameworks (like DaisyUI/Tailwind). Also, icon-only buttons (like those using Lucide icons) completely lack accessible names if not provided an `aria-label`, making their function invisible to screen readers.
**Action:** Always explicitly bind `<label>` elements to their corresponding form controls (`<input>`, `<textarea>`, `<select>`) using the `htmlFor` attribute on the label and matching `id` attribute on the control. For any button where the content is solely visual (e.g., an SVG icon), strictly enforce adding an `aria-label` attribute describing its action.
